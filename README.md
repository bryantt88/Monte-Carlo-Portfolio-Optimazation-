# Monte-Carlo-Portfolio-Optimazation-
This repo contains scripts for the Tenxi ETF portfolio. TenxiETF_MonteCarloWeighting.py runs 100k simulations to optimize asset weights for maximum Sharpe Ratio. TenxiETF_MonteCarloScenario.py stress-tests a $50M initial investment across Bear, Base, and Bull cases to calculate 95% VaR.
